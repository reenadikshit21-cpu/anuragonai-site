Privacy policy

Last updated: 20 October 2026.

AnuragOnAI Publisher ("the app") is a private tool operated by Anurag Dikshit for his own YouTube channel, Anurag on AI. Only the channel owner signs in to it.

What the app accesses

With the owner's permission it uses the YouTube Data API scopes youtube and youtube.upload to upload videos, titles, descriptions, tags and thumbnails to the owner's channel and to change a video's visibility.

What it stores

The sign-in token is stored only on the owner's own computer (a file readable only by the owner). The app does not collect, sell, share or transfer data about any other person. It has no analytics and no advertising.

Google user data

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The owner can revoke access at any time at myaccount.google.com/permissions.

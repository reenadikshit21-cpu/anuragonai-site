The math behind "Claude writes 90% of Claude Code: does that number add up?"

Every input is Anthropic said (A), reported by an outlet (R) or my assumption. Everything else is arithmetic you can redo. Script: claude_code_90_calc.py (Python, no libraries).

1. Where the 90% comes from

“We’ve said before that Claude writes about 90 percent of Claude Code’s own code.” (A) How the Claude Code team does code review, 15 Oct 2026

That post gives no method, no period and no link for the 90%. Claude Code lives in its own repository, separate from Anthropic’s main codebase.

2. The measured number

“As of May 2026, more than 80% of the code we merge into Anthropic’s codebase was authored by Claude.” (A) When AI builds itself, June 2026

Footnote (A): leadership’s “90% or more” estimates include scripts and experimental code; the >80% measures lines merged to production attributable to Claude, and is “more conservative” (attribution gaps; auto-generated code not credited to Claude). Before Claude Code launched (Feb 2025) the share was “in the low single digits”.

4. Are humans typing less?

(A) Typical engineer merged 8× as much code per day in Q2 2026 as in 2024. 8 × 20% = 1.6× the human-typed code of 2024. Assumption: the 80% applies to the same lines as the 8×.

6. Review load

(A) Monorepo changes landing per day: about 2,500 (May) → more than 30,000 (Sept) = 12×. At 10 minutes per review (my assumption): 30,000 × 10 / 60 = 5,000 hours/day = 625 full-time readers (8 h).

7. One engineer’s month

(A) Boris Cherny, 27 Dec 2025: 259 PRs, 497 commits, +40k / −38k lines, “every single line” by Claude Code. Net +2k lines; 8.6 PRs a day.

8. Forecast vs measured

(A) Dario Amodei, 10 Mar 2025: AI writing 90% of the code “in three to six months” = Jun–Sep 2025. Strict measure passed 80% in May 2026: 8–11 months later.

Verdict

As a share of lines, 90% is plausible but unmeasured in public. It is not 90% of the work. “Fewer mistakes” is a ratio: at the stated figures the count of reverts rose about 20%. I didn’t measure anything inside Anthropic; every number is theirs or my arithmetic. Not affiliated with Anthropic. Spot an error? Tell me in the YouTube comments.

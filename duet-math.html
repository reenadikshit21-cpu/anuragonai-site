The arithmetic behind "Claude Duet: does it add up?" (full sheet)

Every input is tagged: T = Anthropic says, R = reported by an outlet or reviewer, A = my assumption. Everything else is arithmetic you can redo. Script: duet_calc.py (Python, no libraries).

1. Background checks (A: interval)

Anthropic says Duet checks connected accounts "every few hours" (T) and that background checks count toward plan usage limits (T). It does not give the interval or the cost of one check.

If the interval is N hours, checks per day = 24 / N.

2. Model reality check (R, NOT a Duet test)

Zapier AutomationBench, Claude Opus 5.5: 263 of 657 tasks passed = 40.0%; 394 of 657 did not (60.0%). Estimated cost $4.22 per attempted task (R, token-price estimate, not billing), so about 4.22 / 0.40 = $10.54 per pass.

3. Safety numbers from Anthropic's other reports (R, NOT about Duet)

Claude Code auto mode: 0.4% false positives on real traffic; 17% of 52 curated overeager actions not blocked (about 9); 5.7% of 1,000 synthetic data-theft attempts not blocked (57 of 1,000).

Browser prompt-injection research, an older model (Opus 4.5): 1.4% attack success after 100 attempts per environment.

Missing number #3: Duet's own failure rate on its safety classifiers: not published (Anthropic says more detail is coming).

Missing number #2

The guaranteed check interval ("every few hours" is the only statement).

What would settle it

Independent tests on real tasks; the safety detail Anthropic promised; a few weeks of real usage bills.
